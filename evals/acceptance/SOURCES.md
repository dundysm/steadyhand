# Where the acceptance notes come from

Each note in this folder is a short description, in our own words, of the pipetting steps of a
published kit protocol. The volumes, times and step order come from the manufacturer's public
manual or protocol page listed below. The number of samples, the plate layout and where reagents
start are ours: the manuals do not say, and a lab would decide them the same way. None of the
manuals' text is reproduced; read the source for the full protocol.
